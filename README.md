# 🌆 Smart City Information Portal Website

The **Smart City Information Portal Website** is a responsive web application developed to provide citizens with easy access to important city information, public services, updates, and issue reporting systems. The website helps improve communication between citizens and city authorities, making city management smarter and more efficient.

This project is designed using modern frontend web technologies to deliver a clean, user-friendly, and interactive experience across different devices.

## 🔹 Concepts Used

- Responsive Web Design
- Modern User Interface (UI/UX)
- Navigation System
- Interactive Web Pages
- Dynamic Functionality using JavaScript
- Structured Web Development using HTML, CSS, and JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎯 Uses of This Website

- Provides quick access to city services
- Helps citizens stay updated with city announcements
- Allows users to report public issues
- Improves digital communication within smart cities
- Creates a centralized platform for city-related information
